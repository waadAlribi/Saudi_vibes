About Saudi Vibes

Saudi Vibes is a student-built web project created to highlight key achievements across the Kingdom of Saudi Arabia. The purpose of this website is to provide a clean, structured, and informative space where users can explore tourism giga-projects, sports events, urban development initiatives, and technology advancements.

The project is developed as part of a university Web Development course and includes various required components such as HTML5 structure, CSS formatting, lists, tables, forms, JavaScript interactivity, and eventually React and backend integration.

Project Goals

  • Showcase Saudi Arabia’s major achievements in an organized way.
  • Practice real web development skills required in course labs.
  • Combine HTML, CSS, JavaScript, and React in one functional project.
  • Create a simple but informative website with multiple pages.

Why Saudi Vibes?

Saudi Arabia is undergoing rapid transformation driven by Vision 2030. This website highlights selected projects that represent innovation, culture, development, tourism, and global engagement.
